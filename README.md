### 🌙 Karachi after dark shouldn’t be scary.

AmanRoute is an AI-powered safety companion designed specifically for women and night-time commuters in Karachi.  
It gives real-time **Safety Scores**, safer route suggestions, one-tap SOS, Fake Call escape, and Voice Guard — all built using real Karachi data.

**Live Demo → [https://amanroute.vercel.app](https://amanroute.vercel.app)**

---

## ✨ Key Features

- **AI Safety Score (1–10)**  
  Based on street lighting, crowd levels, recent reports, police presence, and time of day.

- **Smarter Route Suggestions**  
  Instantly get safer alternative routes when the selected path is high-risk.

- **One-Tap SOS**  
  Sends your live location to trusted contacts + nearest help (Ammi, Bhai, Hostel Warden, Madadgar, IBA Security).

- **Fake Call**  
  Triggers a realistic incoming call to help you exit uncomfortable situations.

- **Voice Guard**  
  Continuously listens for keywords like “help me” and can trigger an alert automatically.

- **Bilingual Support**  
  Works in both **English** and **Urdu**.

- **Privacy First**  
  No login required for SOS • Data stays in Pakistan.

## 🛠️ Tech Stack

- **Maps & Routing**: roadmap.sh / Google Maps
- **Deployment**: Vercel
- **Other**: Real-time location sharing, community reports
